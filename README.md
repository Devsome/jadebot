# JadeBot Userscript

JadeBot is a Tampermonkey userscript for the Silkroad Online web client. It provides various automation and quality-of-life features directly within the game.

## Installation

### 1. Install Tampermonkey

First, install the [Tampermonkey](https://www.tampermonkey.net/) browser extension for your browser.

After installing it, make sure Tampermonkey is enabled.

### 2. Install JadeBot

Once the repository is publicly available, open the userscript:

[Open main.js](https://github.com/Devsome/jadebot/blob/main/main.js)

Then:

1. Click **Raw** in the top-right corner of the GitHub file view.
2. Tampermonkey should automatically recognize the userscript.
3. The Tampermonkey installation page will open.
4. Click **Install**.

Alternatively, you can open the `main.js` file directly through the Raw URL.

### 3. Start the Game

Open the Silkroad Online web client after installing the userscript.

JadeBot will automatically load when the script detects the supported game page.

## Features

JadeBot adds an in-game control panel with features including:

- Automated combat and skill rotation
- Automatic loot handling
- Monster targeting
- Self and party buffs
- Automatic weapon switching for buffs
- Party management and auto-accept
- Job and gathering support
- Inventory and item buff management
- Mastery management
- Leveling area and radius configuration
- Passive mode for support characters
- Stuck and obstacle handling
- Pet and healing management
- Logging and debugging tools

Settings are stored locally and, where applicable, are saved per character.

## Requirements

- A desktop browser
- Tampermonkey
- Access to the Silkroad Online web client
- JadeBot userscript installed and enabled
